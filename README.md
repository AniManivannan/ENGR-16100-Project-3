PID Tuning instructions:
  1. For base power guess and check a power until it gets close as possible to the target speed
  2. For kP apply resistance to the motor and then see how fast it recovers. Keep adding small amounts to kP and testing until it starts oscillating or seems somewhat unstable.
  3. For kI apply resistance to the motor and then see how fast it recovers. Keep adding small amounts to kI and testing until it starts oscillating or seems somewhat unstable.
